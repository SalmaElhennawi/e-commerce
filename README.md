# e-commerce-app

An Angular-based E-Commerce application for browsing products, managing a cart, and placing orders.

## Project Overview
This project is a frontend E-Commerce web application built using Angular. It provides users with a smooth shopping experience and is designed to work independently or alongside a micro-frontend architecture.

## Technologies Used
- Angular
- TypeScript
- HTML / SCSS
- npm

## Project Structure
- src/: Main Angular application
- assets/: Images and static files
- db.json: Mock data for products

## How to Run
1. Install dependencies:
   npm install
2. Run the application:
   ng serve
3. Open browser at:
   http://localhost:4200

## Features
- Product listing
- Shopping cart
- Responsive UI

## Notes
This project can integrate with a micro-frontend architecture (see Micro-Frontend repository [https://github.com/SalmaElhennawi/Micro-Frontend]).
